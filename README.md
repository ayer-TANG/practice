# 摘务

把一段聊天记录粘进网页，自动抽出「要做什么 + 什么时候前做完」，按紧急度排好序。

纯前端、零依赖、完全离线。聊天记录不离开你的浏览器。

## 使用

1. 用浏览器打开 `index.html`（本地双击即可）
2. 粘贴一个聊天窗口里的消息（第一版按 ≤10 条设计）
3. 点「抽取」
4. 核对结果：手动补上漏掉的，删掉误判的
5. 复制结果或下载 `.md`

## 它是怎么工作的，以及它的局限

识别用的是**规则（正则 + 词表）**，不是大模型。好处是零成本、完全离线、聊天记录不出本机；
代价是**中文口语里的任务会有一部分识别不出来**——尤其是没写时间、语气随意的那类，而那类恰恰最容易忘。

所以网页里提供了手动补漏入口：**规则负责筛，你负责兜底**。这不是临时妥协，这是第一版的定位。
