# 03 — Delivery（交付层）

让结果能离开网页。

## 状态

**不存在。** 计划在 Phase 7 实现。

## 职责

- `renderMarkdown(tasks) => string` —— **纯函数**，字符串进、字符串出
- 复制到剪贴板
- 下载 `.md` 文件

## 硬约束

1. **`renderMarkdown` 必须是纯函数**，只有"复制/下载"这两个动作触碰浏览器 API
2. **不得被领域层依赖**
3. 不得修改 `Task`
4. 不得引入第三方 markdown 库——手写模板字符串即可

## 当前状态

| 项 | 状态 |
|---|---|
| `renderMarkdown` | 不存在 |
| 复制到剪贴板 | 不存在 |
| 下载 `.md` | 不存在 |

## 依赖

- 允许：领域层的 `Task` 类型（只读）
- 禁止：反向被依赖；修改 `Task`；网络请求

## 测试

- `renderMarkdown`：纯函数测试，验证输出包含任务描述、截止时间、分组结构
- 复制 / 下载：人工验证，Chrome 与 Edge 各一次
- 边界：空任务列表、全部任务无截止时间、任务描述含特殊字符（`|`、换行、`` ` ``）

## 扩展点

- 新增导出格式（CSV / JSON / ICS）：新增 renderer，不动领域层
- 推送到第三方待办：新增 adapter。**属 v2，当前为非目标**

## 风险

| 风险 | 说明 |
|---|---|
| 剪贴板权限 | `navigator.clipboard` 在 `file://` 协议下可能受限。若失败需回退到 `document.execCommand('copy')` 或提供"选中文本手动复制"。**实现时必须实测 `file://` 场景**，不要假设 HTTPS 下的行为 |
| 下载在 `file://` 下的行为 | `Blob` + `URL.createObjectURL` 通常可用，但也需实测 |
